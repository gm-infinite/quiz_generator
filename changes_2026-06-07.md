## The 9 tasks

**1. Foundation fields** (`2d1d095`)
Added to `SessionState`: `question_count`, `started_at`, `elapsed_seconds`, `practice_history`, `round_scores`, `confidence_ratings`. All defaulted so nothing else broke.

**2. Wrong-answer study list** (`074a750`)
Orchestrator now archives each practice round into `practice_history` before it's overwritten. The final report ends with a "Questions to review" section — every missed question across all rounds, grouped by round, with your answer, the correct answer, and the explanation.

**3. Session timer** (`ab77c28`)
`started_at` stamped at `start()`, `elapsed_seconds` computed at finalize. Report shows `Xm Ys`.

**4. Configurable question count** (`7b91bb4`)
A 5–20 slider on the setup screen. *(TDD — test asserts the agent requests exactly the chosen count.)*

**5. Score progression chart** (`3157804`)
`round_scores` accumulates diagnostic + each practice score. Report renders an inline CSS bar chart — green bars at/above the 70% pass line, orange below. No matplotlib.

**6. Session JSON export** (`a52c0fb`)
A "Download session JSON" button on the report serializes the full session (scores, questions, answers, history, confidence) to a temp file.

**7. Confidence rating** (`e5f3a3b` + `8e4973e`)
Low/Medium/High radios under each question. New `confidence_adjusted_accuracy()` weights a correct-but-low-confidence answer at 0.5× — so a topic you "guessed right" can still be flagged weak and drilled. Wired into both the weakness analyzer and the loop-back recompute. *(TDD — 5 tests on the math.)* Falls back to plain accuracy when no ratings exist, so old behavior is unchanged.

**8. Session history** (`7540450` + `5f09c4e`)
New `session_storage` module persists a one-line summary per completed session to `~/.quizmind/sessions.jsonl`. A "Session history" accordion on the home screen shows the last 20 with a refresh button. Write failures are swallowed so a bad disk state can never crash a quiz. *(TDD — 6 tests.)*

**9. Keyboard navigation** (`4c889aa`)
Self-contained JS: press **1–4** to pick the focused question's answer and auto-advance to the next. Skips confidence radio groups so number keys only drive answers.

## Design decisions (UX vs. complexity)
- **Chart is pure CSS/HTML**, not matplotlib — keeps the zero-new-deps promise and matches the dark theme.
- **Confidence uses a 0.5× weight, not a binary penalty** — graceful, not a cliff.
- **Confidence/history are additive** — every change falls back to old behavior when the new data is absent, which is why all 52 original tests still pass untouched.
- **Determinism rule respected** — all new scoring is pure Python in `tools/scoring.py`; no new LLM calls were added, so **API cost is unchanged (zero for these features)**.

## Note
All UI changes (`ui/views.py`) are covered only by a build-smoke check, not unit tests — that matches the existing repo, which has no UI tests. Worth a manual `python app.py` pass before you demo to confirm the radios, chart, and keyboard nav feel right in the browser.
